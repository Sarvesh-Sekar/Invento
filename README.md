# 🏷️ Invento

**Invento** is an Inventory Management System designed for a **single organization**, built to efficiently manage stock, purchases, and sales with a clean user interface and a robust backend.

---

## 🚀 Tech Stack

### Frontend
- ⚛ **React.js** — For building an interactive and responsive user interface.

### Backend
- 🐍 **Django** — Backend framework providing a strong MVC structure.
- 🌐 **Django REST Framework (DRF)** — For building RESTful APIs that connect the React frontend and Django backend.
- 🧩 **Django ORM** — For database interactions in an object-oriented manner.

### Database
- 🐘 **PostgreSQL** — A reliable, scalable, and SQL-compliant relational database.

---

## ✨ Features
- 🔹 Manage and track inventory (add, update, delete items)
- 🔹 Monitor stock levels with alert system for low-stock items
- 🔹 Record sales and purchase transactions
- 🔹 Detailed and dynamic dashboard to view metrics
- 🔹 RESTful API integration between frontend and backend
- 🔹 Secure CRUD operations powered by Django ORM and PostgreSQL
